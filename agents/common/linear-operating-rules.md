# Linear Operating Rules

Linear is preferred when available, but the project can run locally with task
envelopes when Linear is not connected.

## Issue Rules

- One issue equals one deliverable.
- Every issue has owner agent, acceptance criteria, and verification steps.
- Large work becomes an epic plus sub-issues.
- Blockers are captured immediately.
- Review findings with `revise` or `reject` verdicts become comments or child issues.
