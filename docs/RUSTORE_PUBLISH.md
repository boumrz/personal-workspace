# Публикация приложения в RuStore

Аккаунт RuStore у вас уже есть. Ниже — пошаговая инструкция по сборке AAB и загрузке в RuStore.

## 1. Сборка AAB (Android App Bundle)

### Вариант A: EAS Build (рекомендуется)

1. Установите EAS CLI и войдите в аккаунт Expo:
   ```bash
   npm install -g eas-cli
   eas login
   ```

2. В корне проекта выполните:
   ```bash
   cd mobile
   eas build:configure
   ```
   При необходимости выберите Android и создайте профиль `production`.

3. Соберите релизный AAB:
   ```bash
   eas build --platform android --profile production
   ```

4. Дождитесь окончания сборки. Ссылку на скачивание AAB вы получите по email и в [expo.dev](https://expo.dev) → ваш проект → Builds.

5. Скачайте файл `.aab` — он подписан EAS и готов к загрузке в RuStore.

### Вариант B: Локальная сборка

Требуются Android Studio и настроенный keystore для подписи. В папке `mobile`:

```bash
npx expo run:android --variant release
```

Артефакт будет в `mobile/android/app/build/outputs/bundle/release/`. Для RuStore нужен AAB: при использовании Expo можно сгенерировать его через `eas build` или настроить вручную в Android Studio.

## 2. Подготовка материалов для карточки

Перед загрузкой в RuStore подготовьте (см. `docs/RUSTORE_ASSETS.md`):

- Иконку приложения (та же, что на устройстве)
- Скриншоты реального интерфейса (дашборд, транзакции, добавление операции и т.д.)
- Название и краткое/подробное описание на русском
- Ссылку на политику конфиденциальности (разместите `docs/PRIVACY_POLICY.md` на вашем сайте)
- Категорию и возрастную маркировку

## 3. Загрузка в RuStore Консоль

1. Войдите в [RuStore Консоль](https://www.rustore.ru/developer).

2. Создайте приложение (если ещё не создано): «Добавить приложение» → введите название «Финансовый помощник», выберите категорию (например, «Финансы»).

3. Создайте новую версию: «Добавить версию» / «Новая версия».

4. Загрузите AAB в разделе версии.

5. Заполните карточку: иконка, скриншоты, краткое и подробное описание, ссылка на политику конфиденциальности, возрастная категория.

6. **Обязательно** в поле «Комментарии для модераторов» укажите **тестовый логин и пароль** для проверки авторизации (требование RuStore).

7. Отправьте версию на модерацию.

## 4. После модерации

- При одобрении приложение появится в RuStore и будет доступно для установки.
- При отклонении исправьте замечания в RuStore Консоли и загрузите новую версию или обновите описание/скриншоты.

## 5. Обновления

Для каждой новой версии: увеличьте `version` в `mobile/app.json` (и при необходимости `versionCode` в настройках Android), соберите новый AAB, в RuStore Консоли создайте новую версию, загрузите файл и отправьте на модерацию.
