# Материалы для публикации в RuStore

Перед загрузкой приложения в RuStore подготовьте следующие материалы по [требованиям RuStore](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps).

## 1. Иконка приложения

- **Требование:** иконка на витрине должна совпадать с иконкой приложения на устройстве.
- **Где задать:** в проекте мобильного приложения используются:
  - `mobile/assets/icon.png` — основная иконка (1024×1024 для Expo, для RuStore достаточно 512×512).
  - `mobile/assets/adaptive-icon.png` — для Android (foreground, 1024×1024).
- **Рекомендация:** замените файлы в `mobile/assets/` на ваши иконки (одинаковый стиль для веб-версии и мобильного приложения). Можно использовать `public/icon-192.png` из веб-проекта как основу и увеличить до 512×512.

## 2. Скриншоты

- **Требование:** скриншоты должны показывать реальный интерфейс и функциональность приложения (не только экран входа или заставку).
- **Рекомендуемые экраны для скриншотов:**
  1. Экран входа / регистрации
  2. Дашборд (баланс, доходы/расходы, график по категориям)
  3. Список транзакций
  4. Форма добавления операции
  5. Категории или профиль
- Сделайте скриншоты на реальном устройстве или эмуляторе после запуска приложения.

## 3. Название и описание

- **Название:** без эмодзи и спецсимволов (если не часть бренда). Должно совпадать с названием приложения на устройстве (в `mobile/app.json` задано: «Финансовый помощник»).
- **Краткое описание:** назначение приложения, без кликбейта.
- **Подробное описание:** на русском языке. Ниже — шаблон для вставки в карточку RuStore.

### Шаблон подробного описания

```
Финансовый помощник — приложение для учёта личных доходов и расходов.

Возможности:
• Учёт транзакций: добавление доходов и расходов с привязкой к категориям и дате
• Дашборд: баланс, итоги по доходам и расходам, график расходов по категориям
• Категории: настройка своих категорий с цветом и иконкой
• Планируемые расходы и накопления (в веб-версии; в мобильной — по мере развития)
• Профиль: имя, дата рождения и другие данные

Данные хранятся на сервере и привязаны к вашему аккаунту. Работает совместно с веб-версией приложения — один аккаунт для входа с телефона и с компьютера.

Для работы необходимо подключение к интернету и регистрация в приложении.
```

## 4. Политика конфиденциальности

- **Требование:** обязательна ссылка на политику конфиденциальности при работе с персональными данными.
- **Файл:** текст политики — в `docs/PRIVACY_POLICY.md`.
- Разместите этот текст на вашем сайте (например, отдельная страница) и укажите её URL в карточке приложения в RuStore.

## 5. Категория и возрастная маркировка

- **Категория:** например, «Финансы» или «Продуктивность» (выберите подходящую в RuStore Консоли).
- **Возрастная категория:** укажите по правилам RuStore (для приложения учёта финансов обычно 0+ или 6+).

## 6. Комментарии для модераторов

- В поле «Комментарии для модераторов» **обязательно** укажите тестовый логин и пароль для проверки авторизации (требование RuStore).
