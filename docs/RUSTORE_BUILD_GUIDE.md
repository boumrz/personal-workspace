# Пошаговая инструкция по сборке и публикации в RuStore

## Что уже сделано

1. **Проект инициализирован на Expo** — создан проект `@boumrz/finance-assistant`
2. **Настроен production профиль** в `eas.json`:
   - Сборка AAB (Android App Bundle) — формат, требуемый для RuStore
   - API URL для production: `https://domiknote.ru/api`
3. **Настроен app.json**:
   - Название: «Финансовый помощник»
   - Пакет: `ru.financeassistant.app`
   - Версия: 1.0.0 (versionCode: 1)
4. **Вы авторизованы в EAS** (аккаунт `boumrz`)

---

## Шаг 1: Запуск сборки (ВЫПОЛНИТЕ ВРУЧНУЮ)

Откройте терминал в папке `mobile` и выполните:

```bash
cd mobile
npx eas build --platform android --profile production
```

### Что произойдёт:

1. EAS спросит: **"Would you like to generate a new Android Keystore?"**

   - Ответьте: **Y** (yes)
   - Это создаст ключ подписи приложения (храниться на серверах Expo)

2. Сборка будет отправлена в очередь на EAS Cloud
3. Дождитесь завершения (~10-20 минут)
4. В конце появится ссылка на скачивание AAB файла

### Если сборка уже запущена:

Проверить статус: `npx eas build:list`

---

## Шаг 2: Скачайте AAB файл

После завершения сборки:

1. Перейдите на https://expo.dev/accounts/boumrz/projects/finance-assistant/builds
2. Найдите последний успешный билд
3. Нажмите "Download" — скачается файл `application-xxx.aab`

---

## Шаг 3: Подготовка материалов для RuStore

### 3.1 Скриншоты (сделайте на телефоне или эмуляторе)

Нужно минимум 2-4 скриншота реального интерфейса:

- Экран входа/регистрации
- Дашборд (главная с балансом и графиком)
- Список транзакций
- Добавление транзакции

**Формат:** PNG или JPEG, размер от 320x480 до 3840x2160

### 3.2 Иконка приложения

Используйте `mobile/assets/icon.png` (или создайте новую 512x512 px)

### 3.3 Описание приложения

**Краткое описание (до 80 символов):**

```
Приложение для учёта личных доходов и расходов
```

**Полное описание:**

```
Финансовый помощник — приложение для учёта личных доходов и расходов.

Возможности:
• Учёт транзакций: добавление доходов и расходов с привязкой к категориям и дате
• Дашборд: баланс, итоги по доходам и расходам, график расходов по категориям
• Категории: настройка своих категорий с цветом и иконкой
• Накопления: отслеживание целей накопления
• Профиль: имя, дата рождения и другие данные

Данные хранятся на сервере и привязаны к вашему аккаунту. Работает совместно с веб-версией приложения — один аккаунт для входа с телефона и с компьютера.

Для работы необходимо подключение к интернету и регистрация в приложении.
```

### 3.4 Политика конфиденциальности

Файл уже создан: `docs/PRIVACY_POLICY.md`

**ВАЖНО:** Разместите этот текст на вашем сайте и получите публичную ссылку.
Например: `https://domiknote.ru/privacy` или `https://your-github.github.io/finance-assistant/PRIVACY_POLICY`

## Шаг 4: Загрузка в RuStore Консоль

### 4.1 Вход в консоль

1. Откройте https://www.rustore.ru/developer
2. Войдите в свой аккаунт разработчика

### 4.2 Создание приложения (если ещё не создано)

1. Нажмите **"Добавить приложение"**
2. Введите название: **Финансовый помощник**
3. Выберите категорию: **Финансы**

### 4.3 Создание версии

1. Перейдите в ваше приложение
2. Нажмите **"Добавить версию"** или **"Новая версия"**
3. Загрузите скачанный AAB файл

### 4.4 Заполнение карточки

1. **Иконка:** загрузите `icon.png`
2. **Скриншоты:** загрузите 2-4 скриншота
3. **Краткое описание:** вставьте текст выше
4. **Полное описание:** вставьте текст выше
5. **Политика конфиденциальности:** укажите URL

### 4.5 Возрастная категория

Выберите **0+** или **6+** (приложение без контента 18+)

### 4.6 ОБЯЗАТЕЛЬНО: Тестовые данные для модераторов

В поле **"Комментарии для модераторов"** укажите:

```
Тестовый аккаунт для проверки:
Логин: test@example.com
Пароль: test12345

Или зарегистрируйтесь через форму регистрации в приложении.
```

**ВАЖНО:** Создайте тестовый аккаунт заранее на вашем сервере!

### 4.7 Отправка на модерацию

1. Проверьте все поля
2. Нажмите **"Отправить на модерацию"**
3. Ожидайте ответа (обычно 1-3 рабочих дня)

## Шаг 5: После модерации

### Если одобрено:

Приложение появится в RuStore и будет доступно для установки!

### Если отклонено:

1. Прочитайте причину отклонения
2. Исправьте замечания
3. Загрузите новую версию

---

## Обновление приложения в будущем

Для каждого обновления:

1. Увеличьте версию в `mobile/app.json`:

   ```json
   "version": "1.0.1",
   "android": {
     "versionCode": 2,  // увеличивайте на 1 каждый раз
     ...
   }
   ```

2. Соберите новый AAB:

   ```bash
   npx eas build --platform android --profile production
   ```

3. В RuStore Консоли создайте новую версию и загрузите AAB

## Полезные команды

```bash
# Проверить статус сборок
npx eas build:list

# Посмотреть логи сборки
npx eas build:view

# Скачать артефакт (AAB)
npx eas build:download

# Проверить аккаунт
npx eas whoami
```
