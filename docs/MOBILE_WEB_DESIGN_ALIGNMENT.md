# Выравнивание дизайна Android-приложения с веб-версией

Документ описывает различия между веб-приложением (React + CSS Modules) и мобильным приложением (React Native / Expo) и план приведения Android-приложения к виду веб-версии по скринам.

---

## 1. Контекст из диалога (транскрипт)

В диалоге был выбран путь **React Native + Expo** для нативных iOS/Android приложений при сохранении веб-версии. Предусмотрена общая папка `shared/` для типов, API и утилит. В мобильном приложении уже используются `shared` (типы, API), общая тема в `mobile/src/theme.ts` (аналогично веб `src/styles/tokens.css`), но **UI экранов и компонентов сильно упрощён** и не повторяет структуру и визуал веба.

---

## 2. Общая архитектура

| Аспект        | Веб (src/)                                     | Мобильный (mobile/src/)                |
| ------------- | ---------------------------------------------- | -------------------------------------- |
| **Стек**      | React, Rspack, Ant Design, Chart.js, RTK Query | React Native, Expo, React Navigation   |
| **Стили**     | CSS Modules + tokens.css (светлая/тёмная тема) | StyleSheet + theme.ts (только светлая) |
| **Навигация** | React Router + BottomNavigation                | React Navigation (tabs + stacks)       |
| **Данные**    | FinanceContext + RTK Query                     | AuthContext.api (fetch из shared)      |
| **Заголовки** | PageHeader (h1 + extra)                        | Stack header (title в навбаре)         |

Токены цветов и радиусов в `theme.ts` уже сопоставлены с веб `tokens.css`, но в мобильном приложении **нет тёмной темы**, **нет секционной вёрстки как на вебе** и **много экранов без аналогов веб-компонентов**.

---

## 3. Сравнение по экранам (по скринам веб-версии)

### 3.1 Профиль («Мой профиль»)

**Веб (целевой вид по скрину):**

- Заголовок по центру: «Мой профиль».
- **Кошелёк**: большая карточка с **зелёным градиентом** (баланс), слева иконка кошелька в квадрате, справа «Баланс» + крупная сумма (белый текст).
- **Цели**: заголовок «Цели», справа круглая синяя кнопка «+» для добавления цели. Карточки целей: иконка (target), название, «111 ₽ / 1 111 ₽», прогресс-бар, процент справа (10% / 100% зелёным), ряд кнопок: минус, плюс (синяя), карандаш, корзина.
- **Настройки**: заголовок «Настройки». Два пункта: «Данные профиля» (иконка человека, подпись «Роман • 13.01.2026») и «Тема оформления» (иконка лампы, «Светлая»), справа стрелка.
- Внизу красная кнопка «Выйти из аккаунта» с иконкой выхода.
- Нижняя навигация: Операции, Дашборд, Накопления, Профиль (активен синим).

**Мобильный (текущее состояние):**

- Заголовок стека «Профиль», не «Мой профиль».
- Карточка баланса — обычная светлая карточка (bgCard), без зелёного градиента и иконки кошелька.
- **Цели отсутствуют**: нет секции целей, API goals в shared есть, но в ProfileScreen не вызывается.
- Настройки: только «Данные профиля» и «Категории»; нет «Тема оформления».
- Редактирование профиля — инлайн форма на той же странице, а не переход в «Данные профиля» как на вебе.
- Кнопка выхода есть, но без иконки и не в виде красной окантовки как на вебе.

**Что нужно для соответствия вебу:**

1. Добавить заголовок экрана «Мой профиль» (в стеке или кастомный header).
2. Карточка баланса: зелёный градиент (income-muted-dark → income-muted-darker), иконка кошелька слева, белый текст.
3. Секция «Цели»: загрузка goals через `api.getGoals()`, карточки с прогресс-баром, кнопки минус/плюс/редактировать/удалить, кнопка добавления цели.
4. Настройки: два пункта — «Данные профиля» (переход в редактирование/модал) и «Тема оформления» (переключатель светлая/тёмная); иконки в кружках, подписи как на вебе.
5. Кнопка выхода: красная обводка, иконка выхода, текст «Выйти из аккаунта».
6. Нижние табы: те же 4 пункта, иконки как на вебе (не эмодзи).

### 3.2 Накопления

**Веб (целевой вид):**

- Заголовок «Накопления».
- Сетка 2×2 карточек: **Баланс** (оранжевая иконка), **Накоплено** (зелёная), **% от дохода** (фиолетовая), **Записей** (тёмно-фиолетовая). У каждой иконка в квадрате, подпись и значение.
- Поле поиска «Поиск по описанию» с кнопкой-лупой справа.
- Список по датам: заголовок даты («23 января, 2026»), элементы с зелёной иконкой, описание, подпись «Сбережение», сумма «+ P11 111,00», время, иконка удаления.
- FAB по центру снизу (синий круг с «+»).

**Мобильный (текущее состояние):**

- Одна карточка «Всего накоплений» и сумма.
- Список элементов без группировки по датам; элемент: сумма, описание, дата, кнопка «Удалить» текстом.
- Нет сетки 4 метрик, нет поиска, нет FAB.

**Что нужно:**

1. Заголовок «Накопления» в шапке стека.
2. Сетка 2×2: Баланс, Накоплено, % от дохода, Записей — с иконками и цветами как на вебе (WalletOutlined, RiseOutlined, PercentageOutlined, History/Clock и т.п.).
3. Поле поиска + кнопка поиска.
4. Группировка списка по дате, формат даты «D MMMM, YYYY» (например «23 января, 2026»).
5. Элемент списка: иконка в квадрате (зелёный фон), название, тег «Сбережение», сумма зелёным «+ ₽…», время, иконка корзины.
6. FAB «+» внизу по центру для добавления накопления.

### 3.3 Отчёт / Дашборд

**Веб (целевой вид):**

- Заголовок «Отчёт».
- Блок «Этот месяц» с кнопками «<» «» для смены месяца.
- Две карточки: доходы и расходы за месяц (суммы).
- Блок «Динамика баланса»: зелёный треугольник вверх + сумма изменения, «Начальный баланс», «Конечный баланс», **линейный график** баланса по датам.
- Переключатель «Расходы» / «Доходы», **кольцевая диаграмма** по категориям, в центре «Все категории» и сумма.
- Нижняя навигация с активным «Дашборд».

**Мобильный (текущее состояние):**

- Одна карточка баланса, два блока «Доходы»/«Расходы».
- Круговая диаграмма (PieChart) только по расходам, без переключателя расходы/доходы.
- Нет «Этот месяц» и навигации по месяцам, нет графика динамики баланса, нет центра с «Все категории» и суммой в кольце.

**Что нужно:**

1. Заголовок «Отчёт».
2. Селектор месяца «Этот месяц» + кнопки переключения месяца.
3. Две карточки: доходы и расходы за выбранный месяц.
4. Секция «Динамика баланса»: изменение (стрелка вверх/вниз + сумма), начальный/конечный баланс, линейный график (например react-native-chart-kit LineChart или victory-native).
5. Переключатель «Расходы» / «Доходы» и кольцевая диаграмма с центром «Все категории» + сумма.
6. Опционально блок «По неделям» как на вебе.

---

### 3.4 Операции

**Веб (целевой вид):**

- Заголовок «Операции», справа иконки фильтра и ещё одна (корзина/управление).
- Сегменты «Актуальные» / «Планируемые».
- Поиск «Поиск по ключевым словам» с кнопкой-лупой.
- Список по датам: под датой дневной итог «▼ P12 222,00» (красный) или «▲ P14 322,00» (зелёный). В каждой операции: иконка категории в круге, описание, категория, тег «Расход»/«Доход», сумма +/- и время, иконка удаления.
- FAB «+» внизу.

**Мобильный (текущее состояние):**

- Заголовок «Операции», справа текст «Добавить».
- Плоский список операций без табов «Актуальные/Планируемые», без поиска, без группировки по дате и без дневного итога.
- Элемент: категория, дата, описание, сумма, кнопка «Удалить» текстом. Нет иконок категорий, нет тегов «Расход»/«Доход».

**Что нужно:**

1. Заголовок «Операции», в header справа — иконка фильтра (и при необходимости иконка добавления или оставить «Добавить»).
2. Табы «Актуальные» / «Планируемые» (планируемые — planned expenses из API).
3. Поле поиска + кнопка поиска.
4. Группировка по дате, для каждой даты — итог дня со стрелкой и цветом (▲ зелёный / ▼ красный).
5. Элемент операции: иконка категории (цвет фона из category), описание, название категории, pill «Расход»/«Доход», сумма со знаком и цветом, время, иконка корзины.
6. FAB «+» для добавления операции.

## 4. Нижняя навигация

**Веб:** иконки Ant Design (WalletOutlined, DashboardOutlined, DollarOutlined, UserOutlined), подписи Операции, Дашборд, Накопления, Профиль. Активный таб — синий цвет.

**Мобильный:** эмодзи (💳, 📊, 💰, 👤). Стили табов уже с accent для активного.

**Что нужно:** заменить эмодзи на иконки (например @expo/vector-icons или react-native-vector-icons), чтобы визуально совпадать с веб-версией.

---

## 5. Общие рекомендации

1. **Тема:** добавить в мобильное приложение тёмную тему (как в вебе `[data-theme="dark"]`) и переключатель в профиле «Тема оформления».
2. **Заголовки экранов:** везде использовать те же формулировки, что и на вебе («Мой профиль», «Накопления», «Отчёт», «Операции»), при необходимости кастомный header вместо только stack title.
3. **Иконки:** единый набор иконок (цели, настройки, категории, доход/расход и т.д.) — на вебе через IconRenderer + iconList; в мобильном стоит ввести те же смыслы (иконки из одного набора или те же названия).
4. **Карточки и отступы:** сохранять радиусы из theme (radiusLg, radius2xl), отступы 16/24, тени (elevation/shadow) как на вебе.
5. **Цели на бэкенде:** API целей в shared уже есть; в мобильном нужно интегрировать getGoals/createGoal/updateGoal/deleteGoal и UI целей в ProfileScreen.
6. **Планируемые расходы:** на вебе есть таб «Планируемые» и API planned expenses; в мобильном — добавить таб и использование соответствующего API из shared.
